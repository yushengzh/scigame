# EXP-TEMPORAL-PRODUCTION-004

This separately frozen operational cohort starts after EXP-TEMPORAL-PRODUCTION-001 through EXP-TEMPORAL-PRODUCTION-003 produced 18 cumulative accepted families. Its purpose is to obtain at least two additional accepted families without changing the scientific admission, source-review, deterministic-construction, or task-validation rules. Because earlier outcomes were already observed, this cohort must be reported separately and cannot estimate a preregistered conversion rate or causal pipeline effect.

The inclusive source window is 2026-01-01 through 2026-09-03. The first two records are the complete eligible Nature set from the frozen Nature/Science supplemental audit. The remaining 49 records are the complete eligible Physical Review Letters volume 137 set from its frozen candidate audit. All 51 records must be processed in order; no source may be replaced, and processing must not stop when the target is reached.

Record retrieval and identity adjudication are separate. Crossref relations, independent official arXiv DOI/title queries, and quoted full-title web search retrieve candidates. Search-provider details, literal queries, times, and candidate URLs are retained in the source audit. Every frozen record is confirmed by an exact canonical journal DOI in official arXiv metadata and Crossref. A title match, author match, matching number, topic similarity, search result, or search rank is not identity evidence.

The Code Agent authors only formula, parameters, controls, readouts, domain, and anchors. Deterministic code generates the budget, diagnostic and held-out conditions, public template, provenance mapping, executable case, and task-setting validation. A Code Agent context that did not author a card performs source review; this is process separation, not independent human or domain-expert validation. Human source review remains required before release.

The requested authoring model label is `gpt-5.6-fast`. This interface exposes neither an immutable snapshot nor a documented knowledge cutoff. The effective Temporal boundary is therefore unknown, and the run cannot establish that any family is post-cutoff, unseen, or contamination-free.

The main API runner remains `experiments/run_temporal_conversion.py`. The non-API adapter `experiments/run_temporal_code_agent_production.py` is an emergency execution path for this experiment only and does not replace the main runner.
