# Structured framing debate

This is a transparent single-agent simulation of the requested writing-team
debate; the side-conversation environment did not permit spawning independent
subagents. The positions are separated so their assumptions and rebuttals can
be inspected rather than blended into an artificial consensus.

## Position A — lead with the paired measurement design

**Claim.** The paper's most defensible scientific question is whether alignment
with familiar laws and disclosure of the correct model family can be separated
in a matched 2 x 2 design. This is the only current element that plausibly
differentiates the project from the nearest interactive-science benchmarks.

**Objection to B.** Process measures based on pre-experiment predictions are useful instruments,
but the current measures depend on model self-reports and have no human
validation. Making them the headline would turn an implementation feature into
an unsupported construct-validity claim.

**Objection to C.** A paper-to-case pipeline with zero accepted cases under its
current policy is a failure-analysis paper, not yet a benchmark-construction
method. It should not displace the implemented 20-family design.

## Position B — lead with observable evidence use

**Claim.** A final prediction score cannot distinguish successful scientific
inference from recall or accidental fit. The most understandable research
problem is therefore how to connect hypothesis, experiment, evidence, and
revision without asking for hidden chain-of-thought.

**Objection to A.** The 2 x 2 result is currently uninterpretable: the tracks use
different final representations, historical alignment has no prior-only
manipulation check, and the run has one model and one repeat. Without process
evidence, the design only supplies four low-powered success rates.

**Objection to C.** Source grounding addresses case quality, not the main
evaluation question. It also creates a policy conflict: strict source-only
branches cannot generally supply the synthetic counterfactuals needed by A.

## Position C — lead with paper-derived benchmark construction

**Claim.** Public historical cases cannot support a credible formal evaluation.
A renewable supply of source-traceable cases is therefore strategically more
important than refining scores on a fixed public suite. The staged TeX-to-card
to-case pipeline also produces concrete methodological failure modes.

**Objection to A.** A public 20-family suite with truths in source cannot support
the paper's strongest eventual capability claim, and minimal synthetic laws may
measure prompt/schema handling rather than scientific generalization.

**Objection to B.** Better trajectory annotation does not repair case leakage or
unsupported Oracle truths. Measurement quality starts with a valid environment.

**Concession.** The latest source-only run has zero accepted cases, so this
position is not empirically ready for a main-conference methods claim.

## Rebuttal and synthesis

Position A accepts B's central criticism and moves the current 80-episode result
to an explicitly exploratory role. It incorporates only the narrow, factual
part of B: ex-ante forecasts can localize observable mismatches in a transcript.
It does not claim that the current aggregate is a validated scientific-reasoning
score.

Position A also accepts C's formal-evaluation criticism. The manuscript states
that the current suite is a public development pack and that a private isolated
pack is required for formal capability claims. It does not claim the incomplete
temporal pipeline already supplies that pack.

Position B accepts that process metrics need a task whose outcome is objectively
scored. It retains the executable `WorldModel` and held-out predictor as the
primary outcome rather than replacing them with an LLM judge.

Position C remains a separate manuscript because its research unit, evidence,
and required baselines differ substantially. Mixing its negative authoring
study into an eight-page 2 x 2 evaluation paper would obscure both stories.

## Editorial decision

Use Draft A as the main manuscript nucleus. Preserve Draft B as an alternative
if human process-label validation becomes strong enough to support it. Preserve
Draft C as a separate future authoring paper after a representative current-policy
cohort yields accepted cases. This decision is based on current evidence, not on
which title sounds more ambitious.
